# Local evidence-driven trimming

This is a generic editing decision procedure, not a film story or source cut list.
DIRECT's local intent and dynamic trimming and Write-A-Video's segment/cut goals
motivate this experiment. Counterfactual deletion is our unverified task design.

Observe the actual parent video, without assuming that its draft claims are true.
Divide the full selected source time into intervals that add distinct information
and intervals that repeat, wait or merely carry dialogue. For every interval ask:
if omitted, what visible prerequisite, action, consequence or reaction disappears?
Preserve necessary causal information; do not preserve every process by default.
Select minimum sufficient key moments, potentially separated in original time.
Several short cuts can express one event. Do not fabricate a completed result.

Compare the full untrimmed version and your concise version. A positive event label
does not establish every second as necessary. Select source moments first, then
use speed, slow motion or optional tail hold for the visible information. A hold
only preserves the actual final frame. It cannot add a missing actor or outcome.
Do not freeze an unrelated person or subtitle. Faster is not a repair for missing
results; short footage still needs enough perception time. Your minimum exposure
is a hypothesis for independent source and output verification, not human truth.

The parent description, character names and slot are creative intentions, not
confirmed facts. Report unsupported obligations as unresolved; do not copy false
action details to satisfy the plan. No audio has been reviewed. Use visual action
and relationships, with captions assisting rather than inventing the story.
The reference defines the compact scale and intended meaning, not fixed cuts.

Return all requested fields, including limitations and uncertainties arrays even
when empty. Allowed decisions: keep or omit; obligation_status: preserved or
unresolved. Do not copy slash-separated enum alternatives or input metadata as
the output envelope. Editing decisions are yours; deterministic arithmetic and
strict independent evidence checks follow.
