# 小范围关键瞬间：GLM 观察与微剪准则 v1

这是传给视觉模型的局部观察准则，不是预设剧情、答案或已经成功的实验。只根据本次真实媒体与帧证据判断。旧 slot 说明是可错的导航，不能当成画面事实。

## 描述事实，并提出下一次观察

- 分别记录可见动作／形态、画中文字、任务解释和未知。人物名字、身份、胜负、原因或关系没有可见证据时保留未知。
- 从六帧概览判断哪里值得细看，并说清当前缺少什么：例如动作如何变化、接触是否出现、结果是否可见、人物是否能辨认。不要默认每个段落都包含某类事件。
- 选择较小的补看区间和一个具体问题，检查六张新帧是否真的解决它。新帧可推翻旧描述；不得为了支持原意忽略相反证据。
- 用提供的帧 ID 指出候选关键变化、入点和出点，再观察各自附近的新帧。参考 PTS 用于定位，不凭空猜未观察秒点。邻域采样不是逐帧观看，稀疏网格的两帧之间可能有未见动作。
- 新帧与原速连续片段分别提供空间状态和过程证据。某个漂亮姿态、人物表情、镜头变化或字幕，不单独证明行动成功、身份改变或因果成立。

## 用关键变化精炼，而不是机械缩时

- 找到真正新增信息的位置：处境建立、可辨认的动作变化、可见结果或必要反应。它们是观察维度，不是固定四镜头模板。
- 一个段落可以保留几个不连续的瞬间，省略重复尝试、等待和没有新增信息的过程。说明每项省略为什么不损害观众理解。
- 独立正常速度片段确认先记录实际看见什么，不接收剪辑答案；随后根据这些事实提出候选入点、关键变化和出点，再看各自邻域。准备、行动和结果之间的联系如果不成立，不用字幕、电影常识或解释补全。
- 每个保留区间用这次候选及邻域确认过的帧 ID 表达边界，不回到其他未经边界精看的概览帧另选切点。保持必要人物和状态连续；不能只保留起手，却声称已经展现接触或结果。

## 按可见作用选择操作

- **正常速度**：清楚呈现必要动作或状态变化，不必每段都使用特殊技巧。
- **加速**：压缩仍需保留的过程；辨认身份、动作转折或重要结果的时间不应顺带压缩。
- **局部慢放**：给实际存在的关键变化更多辨认时间。指出具体什么会因此看得更清楚；把整段无新增信息的过程慢放不算高光。
- **尾帧停留**：只用于最后一帧仍承载重要信息的情况。静止姿态不能代替已经遗漏的动作结果。
- **省略与对照**：通过不同时刻的有效瞬间和前后状态表达变化；不要求所有切点卡音乐，不声称未核验的节拍已经对齐。

明确每个操作保留什么、省略什么、代价是什么。允许关键结果所需的局部时长增加，但最终应检查整体是否更精炼，不能用操作名称代替效果。

## 审看实际微剪

先隐藏目标解释，静音描述实际输出中能辨认的人物、行动、变化与结果，并给出输出时间证据。然后与原速源片对照，检查：

- 必要信息是否丢失，文字是否在承担画面没有表达的内容；
- 入出点是否过早／过晚，反应或结果是否有足够辨认时间；
- 重复、等待和空转是否真的减少；
- 慢放、加速和停留是否有可见作用，是否破坏动作和状态连续。

不为自己的计划辩护。实际输出不支持目标时报告 partial 或 fail，并记录未知；自评通过不等于独立观众通过。不要自动重新规划整片。

## 结束条件

下一次观察必须带来新的可用帧／连续片段，或解决一个明确缺项。重复相同输入、问题、边界或未解决矛盾不算进度，停止并说明局限。格式只允许一次修复，不能把创作失败改名为格式错误重试。本流程不设任意总请求额度；停止依据是有限步骤、真实进度和技术状态。
