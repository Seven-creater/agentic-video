# 局部边界补看

本准则只用于同一事件的未确认边界，不重新解释整段，不删除原有必要信息。

- 分清“寻找原片已有镜头切换”和“在镜头内主动裁切”。二者都可能有用，但改变意图必须说明为何保留同一事件的全部表达要求，不能假称找到了原片切换。
- 旧边界判断、字幕解释和事件理由都是可错的模型记录。新连续帧反证旧判断时，明确撤回旧判断，不把错误理由继续传给剪辑计划。
- 先说明当前缺什么证据，以及什么可见变化会改变决定，再自主指定小范围源时间补看。工具按实际解码时间提供全部连续帧，不保证事件恰好位于该范围。
- 每次观察最多半秒左右（工具上限 0.6 秒），每页六帧、最多四页；最多三次观察。需要更大范围或仍未解决时如实停止，不以结束流程为理由确认。
- 新图必须增加真正未见的解码帧。换图名、编码、抽样目标时间或重复同一问题不算新证据。保留问题和实际覆盖记录，依据新事实缩小未知范围或修改可执行意图。
- 边界只选真正观察过的帧 ID。最终候选必须再看包含本体及连续相邻帧的附件，核验裁切是否丢失必要状态、变化、结果或反应。
- 所有原事件义务仍保留。局部确认不能消除整段目标此前的 partial、文字依赖或人物与动作不确定性。
- 观察有限、问题仍阻塞、已到容量上限或没有新证据时返回 blocked。语义阻塞不是格式错误，不能借 JSON 修复把 blocked 改成 confirmed。
- 局部边界确认之后仍须独立看实际选入短片、核验全部义务、审核实际成片。边界确认不等于成片质量通过。
