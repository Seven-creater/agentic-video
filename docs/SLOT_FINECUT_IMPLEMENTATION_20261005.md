3. GLM结合源时间映射和相邻输出上下文提出1–3种局部操作方案，允许删除、多个不连续

4. GLM自行选择候选并输出整片EDL。最终操作必须与已提方案一致，slot表达义务保持原文。

6. 核心源证据或预计曝光不成立就停止该候选，不渲染。每父级最多一部新渲染，不自动循环。
