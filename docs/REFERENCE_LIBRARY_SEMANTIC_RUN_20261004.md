## 质量问题和端到端断点

1. **参考观察仍偏粗。** 新模型归纳四种宽泛功能，没有充分拆出多次关键动作的省略压缩、
   动作阶段和变速关系。所有源段 speed=1，没有证据证明自主学会慢放或加速。
   完整媒体输入和 30 fps 代理，不保证服务实际逐帧观察或穷尽识别剪法。
2. **长窗口标注仍会误导精切选择。** 第二段独立观察报告熊猫一直躺地，计划的站起未得到
   支持；第四段指向四侠场面，没有明确展示熊猫被指认。局部实际输出抽帧与这些缺项一致。
   金色冲击波可见，但敌人消失／完整胜利结果仍需区分可见结果与推断。
3. **独立事实观察也会误判。** 高清原片 314 秒（对应输出约 30 秒）两手各三碗，共六碗；
   创作计划写四碗，独立 GLM 观察写左臂三碗，两者都有问题。Codex 最初对小尺寸输出的
   四碗判断同样错误，已经撤回；高清帧和修正记录单独保存，不写回模型答案。
4. **模型反证不是实际错误清单。** 批量核对保留 9 项 unsupported、1 项 partial。
   三条字幕检查主要因源烧录文字与新增字幕不一致而拒绝，没有充分核验字幕语义是否
   得到画面支持；不能将这九项简单写成九个已确认剪辑错误。有效反证和可疑反证要分别保留。
5. **盲读和终审仍不可靠。** 盲读明确 text_dependency=essential，还把部分躺地镜头读成
   站立受击、把四侠场面读成熊猫受到欢呼。终审 raw 判断为主旨／剪法／画面叙事 partial、
   连续性 pass，但未完成 ID 绑定和直接视觉矛盾检查。程序没有升级原 non-supported 目标，
   也没有为满足交付伪造成功审阅。
6. **画面尺度与预算限制仍在。** GLM 选择 fit，主体完整但横版素材在竖屏中较小，原电影
   字幕可见。原 16 个窗口额度已满，本次只在这些范围内重选，不代表全库中没有更好素材。

已实施的修复是事实／意图分离、独立精切观察、SHA 绑定、保守质量门和有来源的结构恢复。
本次尚未把事实反证接回一个预算完整的“再选素材→再看→再剪”循环，也未完成参考的
细粒度镜头观察策略。后续应让模型自主提出缺项和观察请求，不能由 Codex 提供替代切点或答案。
