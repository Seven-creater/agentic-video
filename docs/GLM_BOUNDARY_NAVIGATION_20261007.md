新增 `microclip_v2_boundary.py` 为未确认的同一事件、同一边界侧执行有限流程：

1. GLM 明确当前缺项，自主选择寻找原片切换或主动镜头内裁切。
2. 需要补看时，GLM 给出源时间数值范围；CPU 提供范围内全部真实解码帧。每次最多 0.6 秒、每页六帧、最多四页；原锚点在范围外时另页标记非连续比较，容量不足不改为稀疏采样。

4. 提名新的已观察帧之后，再显示候选本体及连续邻帧，只有这一最终确认阶段可追加有效边界凭据。
5. 全部事件边界仍须保持源时间顺序、不重叠；原事件义务与 222 目标核验不变。继续实际切片独立观察、源证据比较和实际输出盲读。

这是有限的证据补充过程，不保证模型的解释正确。最终仍保留原 partial / mixed、文字依赖、动态观察与陌生观众理解限制；局部确认不能建立联合质量通过。
