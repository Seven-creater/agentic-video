## 1. 问题长什么样
雪山试跑直接取 inbox/02_雪山救狐狸/01.mp4，实际 161.9 s，产生 32 格、39 道题；原 e2e 任务用的是 07.mp4（37.9 s）。改正后新开输出目录被拒：`same_inputs_already_registered_use_original_output`；在原目录启动被拒：`output must be a new or empty directory; jobs are never restarted`。

出题规模异常 → 读 reference_catalog/inventory.json 的 duration_s → 对照旧任务 .omni-server/job.json 的 `--reference`。

## 3. 根因
操作问题：模板目录有 10 个候选视频，试跑脚本手写为 01.mp4，没有沿用旧任务的参考路径。第二个问题是对登记规则不熟：同输入只能在原任务下用 `--parent-task` 嵌套重跑。

## 4. 解决方案
