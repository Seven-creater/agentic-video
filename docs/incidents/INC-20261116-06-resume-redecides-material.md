# INC-20261116-06 断点续跑会重新决定素材，后面整条创作链都会重做

| 项 | 内容 |
|---|---|
| 发现日期 | 2026-11-16（华强那次已记为"待改进"，见 `华强_选材检查/待改进_恢复已完成选材阶段.md`） |
| 影响范围 | scene_v1 所有已走过素材浏览阶段的续跑。素材、选角、剧本、配音都会重做，续跑结果不可复现，并重复花 TTS 费用 |
| 状态 | 已修复并验收（release 9de4c74fe95a 起；bf64c94c4da3 上零花费重放通过） |
| 相关提交 | 无 |
| 相关任务 | 18_ 续跑 fast_resume_20261116_032937：24 次调用全部是新请求；华强那 10 次续跑也属同一情况 |

## 1. 问题长什么样
18_ 续跑本来只想重做配画面，结果从 `material_scene_browser_decide_1` 起，24 次调用全部重新请求，台词也变了（l2 从"骑士大人，我记得的"变成"嗯，我都记得"）。`artifacts/material_received_input_revised_*.json` 里记了 browser decide_1~4、decide_cast_1、adaptation_plan、script、story_review 这几步，每一步的输入都变了。

## 2. 怎么查出来的
在服务器上对比新旧两次 decide_1 的请求：原来那次的 `watched` 是空的，新的那次已经预先装了上一轮看过的窗口。代码位置在 `material_browser.py:570 restore_watched()`：续跑时会把祖先账本里收到的盲看结果预先装进 `self.visual`。

## 3. 根因
`restore_watched` 的设计本意是"复用中立的看片观察，但不继承旧的创作选择"。代价是第一个决策请求必然和原来的不一样，按 scene_v1 的 `revised_scene` 规则只能重新请求，之后每一步都跟着重新请求。至于看片调用本身，就算不预先装入，也能靠账本按"同提示、同媒体"原样复用。

## 4. 解决方案
用户 11-16 授权采用方向 (a)：按原顺序原样复用。
- `material_browser.run` 不再调用 `restore_watched`（已删除该方法）；`restore_comparison_progress` 不再从祖先任务读取比较进度。续跑时，导航从第 1 轮开始，按账本逐轮复用已收到的回复；看片请求同样按"同提示、同媒体"复用。只有代码改变了输入的那一步，以及它的下游，才会重新请求。
- 新增"只复用"模式：`resource_guard.before_request()` 在环境变量 `OMNI_REPLAY_ONLY=1` 时，任何新付费请求（GLM、TTS、原声核对）发出之前就抛出 `replay_only_new_paid_request`。启动器加了 `--replay-only` 参数。

## 5. 为什么不用其他方案
- (b) 保持现状：修复效果无法单独验证（18 就是这样）；每次续跑都等于重新抽签，可能暴露新问题；还要重复花 TTS 费用，违反"出错不重跑、定位修根因"。
- 华强"待改进"笔记里提的"校验后复用最终选择"：需要另写一套重放校验逻辑。去掉预装之后，账本已有的逐调用复用就能做到，改动更小。
- 保留预装、只在比对时忽略 watched 字段：会让账本复用规则出现例外，削弱"请求一字不差才复用"的保护。

## 6. 怎么验收
- 单元测试：`test_resume_exact_replay.py`（2 项：只复用模式会拦截新请求；续跑时第一个决策提示与冷启动一致、不预装已看窗口）。`test_browser_comparison.py` 中原来锁定"继承祖先进度"的那项，改为验证"不预装"。服务器全量测试 183 项通过。
- 实跑验收（2026-11-16，bf64c94c4da3）：用 `--replay-only` 续跑 18（trial fast_template_20261116_055227）。共复用 59 次已付费回复（`material_reply_reuse_001~059`），全部来自 18 最初那次运行的账本，覆盖读参考、8 轮素材决策和全部看片、识别、原声核对、选角、选角复核。随后停在这一版新增的"能否分清"检查之前，报 `replay_only_new_paid_request`，账本新增 0 次调用，没有花钱。中间祖先任务因旧的预装行为而产生的不同决策（decide_1~4、decide_cast_1）只记为 input_revised 并跳过，没有被误用。

## 7. 量化数据
18_ 续跑：24 次 GLM 调用全部重做，花了约 50 分钟，7 句台词重新配音。

## 8. 经验与后续
今晚多次说"续跑会复用已付费结果"，对已经走过素材浏览的任务并不成立，需要更正。
