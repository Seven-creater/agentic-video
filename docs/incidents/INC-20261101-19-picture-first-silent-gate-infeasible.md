## 1. 问题长什么样
- picture_first 两次真实运行（不烧心 pf_library、pf_film）都停在 TTS 前的静音门（`silent_story_not_readable` 路径），零成片。
- 具体失败形态（S25 任务说明记载）：像"宁可少赚不坏规矩"这类价值主旨，用三部功夫熊猫素材**无法静音演出**；视觉剧本节拍要么退化成"两个人在说话"，要么变成私有隐喻（"绿光柱=诱惑"）——盲看复述对不上视觉剧本，静音门按设计拦停。
- （推断）pf_film 一路先撞上 INC-20261101-20 的概览 coverage_s 回显停机（9 次调用），该处修复后续跑才走到静音门。

## 2. 怎么查出来的
- 事前调研（调研报告_找画面_静音能讲清故事_20261101.md）逐句抽帧核对 4 条成片，归纳出旧路径的结构性缺陷：先写词再按词找画面 → 字面插图（"路才越走越宽"配山崖走路、"订单像雪片"配舞狮撒红纸、"找上门"配熊猫跑来）、场景跳跃（不烧心原片版静音看是"阿宝回家认亲"）、动作与台词相反（"不接"之后阿宝乐呵呵端面碗）、说话人不在画面、关键信息画面看不到（"渣""拥抱"）。
- 审片报告（6 条成片逐句对照）结论：素材库检索 3:0 胜原片检索；两种方式共同的病灶是"画面没有在演台词的意思"。
- 据此实现 picture_first（97dfa88）并上线实验；两次运行的 silent_gate 判定（盲看 observed_story vs visual_script 逐节拍 told + scene_jumps_confusing）均不通过、一次 plan_1 修订后仍不通过 → 按设计停机。实现本身经 S23 审查 pass（无真实缺陷），失败的是前提假设。

## 3. 根因
- 设计问题（门的标准与素材能力不匹配）：把"静音可读"从验收建议升级为 TTS 前的**硬性零容差门**，默认任何主旨都能被现有素材无声演出。实际上：
  - 价值类/对话类主旨（规矩、取舍、父子情）的载体是对白与价值观冲突，画面上往往只剩"两人对话"，静音天然讲不清；
  - 让模型补"可静音演出"的节拍时，它退化为套话（两个人在说话）或私有隐喻（绿光柱=诱惑），盲看者无从对应；
  - 文献亦提示模型理解图片序列叙事的能力明显弱于人（StripCipher，arXiv 2502.13925），盲看判定本身偏严。
- 实现层无 bug：门如设计生效、恰一次 plan_1、不再检索、二次失败即停、不付 TTS——省钱与拦停都按预期发生。

## 4. 解决方案（缓解）
- 97dfa88 保留的 picture_first 机制（供后续风格复用）：搜索阶段产出 `visual_script`（3–8 节拍 `{beat_id, who, to_whom, action, emotion, outcome, why_silent_readable}`，不含台词字眼，形状校验+一次格式修复）；规划要求先选能演出节拍的连续素材（slot 带 `visual_beat_ids`）再写贴合画面的台词，每句声明 `picture_relation ∈ {sync_speech, parallel, additive, divergent}`，字面插图被明令禁止（提示词附反例）；TTS 前静音门：对实际粗剪跑无脚本盲看 + `silent_check` 文本比对，逐节拍 `{beat_id, told, evidence}` 与 `scene_jumps_confusing`；失败恰一次同窗口 plan_1（禁止新检索），再失败 `silent_story_not_readable` 停止；`silent_gate.json` 记录两轮；resume 复用已录 blind/check 回复，uncertain 绝不重放；默认风格提示词与输入锁逐字节不变（硬编码 sha 测试）。
- 用户 2026-11-01 裁定（"定下来吧"）后的 S25（进行中，未提交）：默认检索回到素材库、默认创作回主旨迁移；静音审核降级为 **advisory 分级**——tier-1 问题（contradiction / keyword_illustration / speaker_mismatch、跳跃困惑）触发恰一次 plan_1 后**无论结果继续**（永不为此停机），`invisible_claim` 仅提示；保留 picture_relation 与说话人可见校验，新增单镜头至多承载 2 句台词；评分记入 `silent_review.json` 与 run outcome 供用户查看。

## 5. 为什么不用其他方案
- 保留硬门、放宽判定（如只要求一半节拍 told）：标准仍由模型盲看主观决定，价值类主旨照样过不了，只是把失败推迟到更晚的阶段。
- 保留硬门、扩大素材库到能演出价值主旨：超出当下能力（需要非功夫熊猫题材），违背"用现有素材"的约束。
- 完全撤销静音审核：字面插图、场景跳跃等问题已被审片证实高频存在，需要至少 advisory 的信号留给用户与修订。
- picture_first 保持默认：两次 0 交付已证伪；降级为可选实验风格保留。

## 8. 经验与后续
- 把一项质量期望升级为零容差硬门之前，先用小样本验证**素材与主旨类型能否满足该标准**；价值类/对话类主旨天然依赖声音，"静音可读"对它们只能作参考信号。
- 盲看判定的严格度受模型能力限制（图序叙事理解弱于人），门与判定者要一起校准，不能只校准门。
- 后续：S25 落地后回填 advisory 评分与成片对照；若 advisory 信号对修订确有指导价值，可再评估有条件的软门（如仅 contradiction 拦停）。需要用户决定的事项：picture_first 实验风格是否保留在 CLI 选项中。
