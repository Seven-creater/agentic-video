## 1. 问题长什么样
（设计变更记录：问题不是一次报错，而是被换掉的旧方向的两类实证病灶。）
- 审片报告（2026-11-01，6 条成片、每句在开头/中间/结尾各抽 1 帧逐句对照字幕）：
  - 素材库检索 3:0 胜原片检索（赵德汉明显胜、不烧心胜、雪山小胜）。原片版病灶：不烧心 3 处字眼插图（"雪片"配舞狮撒红纸、"路越走越宽"配山崖父子、"找上门"配熊猫跑来）、"不接"之后阿宝乐呵呵端一摞面碗（动作与台词相反）、赵德汉 7 句台词换 6 个角色、静音看是"一串互不相干的角色特写"。
  - 两种方式共性：台词关键信息画面上看不到（"渣""拥抱""从天而降"）；偏暗偏静镜头一撑好几句（不烧心中段一个暗镜头撑 3 句约 15 秒）；质问对话说话人对不上。
- picture_first 实验（严静音门）两次真实运行 2/2 停在静音门、零成片（INC-20261101-19）："宁可少赚不坏规矩"类价值主旨无法用三部功夫熊猫素材静音演出，视觉剧本退化为"两个人在说话"或私有隐喻（"绿光柱=诱惑"）。
- 审片报告的方向建议：默认素材库检索、原片只作补缺且找回连续整场戏；同一个镜头不撑超过两句台词。

## 3. 根因
设计问题（旧默认方向的结构性缺陷，非实现 bug）：
- 旧路径"先写词再按词找画面"，且没有任何逐句的"台词-画面"关系约束：模型按字面配图（字眼插图）、按可得性凑镜头（场景散乱、角色特写串烧），校验层无事可拦——审片报告中是高频共性问题而非偶发。
- picture_first 把"静音可读"升级为 TTS 前零容差硬门（INC-20261101-19 详述），标准超出素材与主旨类型的能力：价值类/对话类主旨的载体是对白，画面上只剩"两人对话"。
- 即缺的是"逐句可判定的画面关系纪律＋不拦停的分级审核"，而不是更严的门或更宽的提示词。

## 4. 解决方案
93edb02 落地（S25），新默认 `creative_style: "picture_aware"`：
- **默认与兼容**：全新 `--creative-audio` 任务未给 `--creative-style` 时在输入锁记录 `picture_aware` 并随 detached 启动命令转发；resume/容量恢复按锁复现；旧锁字节不变（历史锁字节测试未改）；`classic`（＝今日行为）与 `picture_first` 仍可选，classic 提示词与裸 prompt 字节等价（sha 钉死）。
- **检索**：不要求 visual_script（丢弃 picture_first 该部分）；搜索提示词仅加一句：优先可见动作/关系/情绪贴合主旨、连续场景优先于散乱镜头。默认检索维持素材库路径，`film` 保留为选项。
- **规划规则**（提示词＋校验器，仅本风格）：每句 audio_draft 行声明 `picture_relation ∈ {sync_speech, parallel, additive, divergent}`（复用 S23 枚举/定义/校验，sync_speech→对白且说话人须在本句镜头可见）；提示词明令禁止字面插图并附反例（"规矩立住了，路才越走越宽"的店铺对话配熊猫走山崖）；单个镜头至多承载 2 句台词（只计 segment_ids 恰为该段的行，跨段行不计入任何单段）；违规反馈点名镜头与行并建议拆分镜头区间或移动台词；其余检查不变。
- **advisory 静音审查**（粗剪渲染后、TTS 前）：先对实际粗剪跑既有盲看提示词，再一次 `silent_review` 文本调用（输入＝盲看故事、参考主旨一句、逐句时间轴：文本/picture_relation/起止/每段画面观察），逐句返回 `{line_id, issue: ok|contradiction|keyword_illustration|speaker_mismatch|invisible_claim, evidence}` 及 `scene_jumps_confusing: bool`、`readable_situation`（tier-2 信息性）。任一 tier-1 问题（contradiction/keyword_illustration/speaker_mismatch）或跳跃困惑→恰一次 plan_1 修订（同一批精看窗口、禁止新检索），再审一次，**此后无论如何继续**（绝不为此停机）；`invisible_claim` 仅提示不触发修订；两轮审查与评分记入 `silent_review.json` 及 run outcome/chain result 供用户查看。
- **费用与纪律**：审查走 GLM 文本调用（与其他阶段同通道），无额外 TTS/Qwen 付费；已录回执 resume 复用；uncertain 绝不重放。
- 通用性：逐句关系枚举与"≤2 句/镜头"是形状规则，与具体模板/影片无关，对任何主旨迁移任务同样成立。

## 5. 为什么不用其他方案
- 维持 picture_first 严门为默认：两次真实运行 2/2 0 交付已证伪（INC-20261101-19）。
- 完全撤销静音审查：字面插图、场景跳跃被审片证实高频存在，用户与修订链需要至少 advisory 的信号。
- 原片检索为默认：审片 3:0 负（散角色串烧）；保留为选项，缺情境时补缺（审片建议）。
- 只改提示词、不加校验器：picture_relation 与"≤2 句/镜头"是可程序判定的形状，提示词服从率有限（参见 INC-20261101-20 的回显教训），校验＋可操作反馈才是可依赖的一层。
- 顺带改写旧任务输入锁以套用新默认：违反历史任务字节不变纪律，旧锁明确不动。
