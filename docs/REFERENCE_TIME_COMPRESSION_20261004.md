# 参考比赛片段的时间压缩与实施方案

2026-10-04。依据固定 `data/ref/video.mp4` 的实际画面、相邻帧对比、已有切镜候选时间线及原始论文。
本轮实施三个事实审核修复，并调研段落内部的时间压缩。没有新模型调用，没有制作第四版电影。
历史任务仍为 58/80 次请求、16/16 个唯一精看窗口、3/3 次授权渲染；004 保持不明。

## 实际参考是怎样压缩过程的

参考 SHA：`2f95e24edd2cf4b79cc1f40f7e202174c53a6abcf084e728bb49e3ca92938a17`，全长约 21.933 秒。
本轮抽取 5–17 秒每 0.25 秒一帧，共 49 帧，另检查八组候选边界两侧相邻帧。
图片、采样时间和证据限制存于原任务 `artifacts/reference_compression_audit_v1/`。
这些观察属于 Codex 的参考审计，不是 GLM 的新回答，也未作为人工替换 EDL 输入。

| 成片时间，约数 | 实际画面 | 表达作用及压缩方法 |
| --- | --- | --- |
| 5.10–6.53 秒 | 红、蓝护具双方和中间裁判；双方鞠躬 | 很短的准备建立同一比赛、人物和对抗关系，无需交代完整规则 |
| 6.53–9.07 秒 | 女生多次踢击，姿势与机位发生跳变 | 6.533、7.133、7.800、8.500、9.067 附近，相邻帧可见明显跳切；保留不同关键动作，省略恢复站位、等待和重复过程 |
| 9.07–13.00 秒 | 一次踢击的展开、接触和对手失衡；动作变化显著放慢 | 关键动作获得比前面各次踢击更长的可读时间，使观众看清能力和效果，形成快切后的强调 |
| 13.00–14.03 秒 | 男生下落至地垫，女生收腿站立 | 保留动作后的可见结果；不能只留下踢腿便断言胜利 |
| 14.03–16.70 秒 | 镜头接近女生，她面露微笑，旁边有观众 | 反应与情绪收束；从“做了什么”转到“取得结果后怎样” |

比赛到微笑的完整单元约 11.6 秒；用户说的“5–15 秒”是对核心片段的概括。
“踢击→倒地→微笑”支持优势与成功的视觉理解，但画面没有展示正式比分或判决，不能凭这些帧核验比赛官方结果。
13.00、14.03 的检测器候选可能涉及动作幅度、速度变化或快速转镜；不一律列为已确认硬切。
实际成片不足以核验原始比赛时长，更不足以算出各镜头原始播放倍速。十分钟是用户说明方法的例子。

它把时间分配给信息价值：准备只需认清关系，几次踢击累积能力证据，决定性接触需要看清，结果和反应负责收束。
主要方法是**跨时刻选取、动作省略、关键动作强调和结果反应连接**。均匀缩短每段或把整场快放，无法保证相同表达。
这种迁移不要求新素材也有比赛或踢腿；GLM 应根据新画面找到能够表达同一主旨的行动、结果和反应。

## 文献支持到什么程度

- **Write-A-Video，ACM TOG / SIGGRAPH Asia 2019**：一个文本段可对应多个镜头，联合考虑单镜头、邻接剪切和整段条件，支持“一个 slot 对多个片段”。其示例包含解说，不能直接证明无声画面的因果表达能力。[作者论文](https://cg.cs.tsinghua.edu.cn/papers/TOG-2019-Write-a-Video.pdf)
- **Learning to Cut by Watching Movies，ICCV 2021**：研究候选镜头之间的切点选择，可帮助判断局部接缝。它不负责从长电影找齐整个主题的事实，也不保证跨片段故事成立；其完整模型包含音频条件。[论文](https://arxiv.org/abs/2108.04294)
- **DIRECT，2026 年预印本**：全局意图到局部剪辑目标，再通过候选序列搜索与滑动窗口裁短片段。可借鉴这种层次与反馈，不照搬其音乐时长安排或放宽语义查询来弱化固定参考。[论文](https://arxiv.org/html/2604.04875v1)
- **On the Consistency of Video Large Language Models in Temporal Comprehension，CVPR 2025**：找出时间区间与判断该区间实际包含什么并不总一致。支持分别验证精切中的动作与结果；它不证明改提示词就能消除 GLM 的观察错误。[论文](https://arxiv.org/html/2411.12951v2)
- **FFmpeg 官方文档**：`setpts` 可调整播放时间；重复源帧的慢放不生成新的动作证据，低帧率素材慢放可能顿挫。运动插帧是另一种操作，当前实现没有开启。[文档](https://ffmpeg.org/ffmpeg-filters.html#setpts_002c-asetpts)

以上支持组件设计，不是已经完成“参考主旨及剪法迁移”的实验结论。下面是针对本项目的组合方案。

## 端到端实施

1. **参考分析记录信息功能与相对时间。** 除“快切、慢放”等名称，记录每个短单元新增什么信息、哪些动作与结果不可删，以及长短节奏。无法观察的原始时长和速度保留未知。参考具体事件不是新故事的固定模板。
2. **检索目标从整件事降到缺失证据。** “训练成功”太宽；应由 GLM 提出需要确认的行动、目标变化、完成结果、反应对象。轻量库索引导航，已有窗口定位，再在需要处精看，不精看全库。
3. **GLM 在窗口内提出多个候选微片段。** 每个候选记录源 SHA、入出点、角色与状态、动作阶段、局部可见事实、信息增量、前后衔接条件和不确定性。重复尝试、对白等待等可以省略，不能省略证明结果的画面。候选没有证据则继续检索或重构 slot，不能补字幕冒充事实。
4. **一个 slot 组织一个片段序列。** 所有 microclip 可来自不连续源区间，但各自必须落在完成精看且被标为可用的范围里。单个片段只证明局部事实，整个序列负责 slot 的含义。人物身份、动作方向、道具与伤势等状态参与组合选择；跨时间蒙太奇不应声称连续同一次动作。
5. **先省略过程，再决定播放速度。** 先删等待和语义重复；默认正常速度。关键接触、动作成果可慢放，非关键重复可加速。每个变速给出观察依据、用途和时间代价。输出时长为 `sum((out-in)/speed + freeze_tail)`；不要把慢放或定格当新事件。
6. **精切事实核查，然后审看真实成片。** 独立短片段观察不知道主题或计划；另一个调用核对计划说法。成片再无声盲读，检查前后关系、结果是否可见以及是否依赖文字才能理解。审核所需的长窗口不能代替精切事实。
7. **按失败原因反馈。** 缺动作/结果则补检索；事件齐全但观众看不清则调整切点或停留；时长冗余则删除无信息镜头；人物断裂则换同一人物的有效证据；有未解决事实冲突则保留 partial。预算内自动进行，不依靠人工写剧情。

不要固定所有片段两秒，不要固定准备/打斗/胜利三段。时长由动作可读性、信息增量和参考节奏共同决定。
角色反应可以增强表达，但无上下文的笑脸不能证明认可；对手倒地也不能凭画面自动证明官方获胜。
字幕仍可辅助，但核心行动与结果应当从静音画面读出；BGM 节奏单独核验，不作为故事事实。

## 本轮已实现与尚未实现

新入口 `--semantic-audit` 包含 editing-v2，在尚无付费计划的任务启用 `visual_narrative_primary_v2`：

- 每个精切以正常速度独立观察，绑定源入出点、源 SHA 和代理 SHA；不提供 slot、参考主题、人物猜测或预设结局。
- 随后按观察 JSON SHA 核对每段 `visual_claims`、身份和文字目标；整个 slot 与剪法关系只在全片审核。
- 盲读分开 `visual_action / visual_outcome / visible_text / inference`；结果声称必须有结果证据。
- 字幕显示时间映射到实际源播放时间，修复“片段后来有该事件，字幕提前显示也通过”的缺口。
- 审核逐个覆盖计划要求与盲读说法，未解决矛盾阻止 pass。已解决的错误盲读保留原记录，不能冒充正确事实，也不能豁免计划要求。
- 最终比较引用核查后的 claim IDs；媒体输入采用实际候选，不能把参考当作候选再次审看。
- 每段预留两次独立调用及各一次格式修复，搜索、计划、盲读、审核和最终比较也预留修复；预算安排持久化，恢复不改已提交提示或重新计数。
- 模型规划明确允许一个 slot 多个不连续短片段及说明变速用途。FFmpeg 已支持每段 0.5–2 倍，段内不同速度可以通过多个段表达。

尚未实现：微片段候选的专用动作阶段数据结构、序列搜索评分、信息增量约束、专门的可变速曲线、自动动作可读性指标，以及真实 GLM 的新协议效果评测。
提示词允许这些行为，不代表 GLM 已熟练做到。结构验证也不能自动证明观察员描述的画面事实一定正确。

本轮用合成媒体和模拟 MCP 测试真实 FFmpeg、来源映射、矛盾门、预算和恢复；没有调用 GLM 验证创作质量。
全套测试 411 passed、2 skipped；随后新增的一个 slot 下不连续双片段与 2 倍／0.5 倍变速集成测试也通过。
该合成案例验证实际裁剪来源和帧量化后的输出时长，不证明角色故事或创意剪辑质量。
旧运行按原协议恢复，新开模式不能改写旧计划或把同一任务搬到新目录重新获得预算。
对当前已完成任务应用新事实审核或制作后续修订，需要原任务内另存、限额的继续工作方式；本次没有追加其模型调用或渲染额度。

下一次研究检验应在同一参考和合法预算下，比较“整段拼接”与“同 slot 多精切”，检验静音内容可读性、关键行动与结果覆盖、人物连续性、时长冗余及成本，而不只比较总时长变短或切点数量变多。
