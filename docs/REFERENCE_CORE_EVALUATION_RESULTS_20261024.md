# 核心主旨评测实测记录（2026-10-24）

本轮从24个模板目录中，先研究含义、核验具体样本，再固定10个模板。每模板4类，共40项。被测对象是原创作项目的参考理解阶段，没有继续配音、剪辑和出片。

**40项均有结果或明确失败／不适用原因；22项取得至少一项有效评分，不等于40项全部有效。** 其中6项前缀题缺少推断合理性字段，仅有主旨吻合分。所有标签仍为模型辅助标注，没有冒充人工金标准。

## 得分与覆盖

| 方法 | 有评分／计划 | 实测成绩 |
|---|---:|---|
| 完整参考主旨理解 | 7/10 | 模板平均完整命中64.3%；16要素完整、5部分、3遗漏、0矛盾 |
| 前几秒推测主旨 | 6/10 | 完整命中0%；4要素部分、17遗漏；合理性指标未完整返回 |
| 长故事主旨匹配 | 7/10 | 首选段落命中14.3%；范围完全正确14.3%；精确率66.3%、召回率89.5% |
| BGM关联原参考 | 2/10 | 有效查询关联命中0/2；其余8项未取得有效成绩 |

评分口径：每个主旨要素对照原模块实际原句，完整表达才计matched；部分、遗漏、矛盾分别计数，不给部分命中随意折算分。模板命中率＝完整要素数／核验有效要素数，再对模板取平均。16/24＝66.7%是合并要素后的比例，与模板均值64.3%权重不同。无分数的任务不当作零分理解样本，也不从覆盖率的分母删除。

故事首选命中＝所选第一个段落ID属于目标段落；范围完全正确＝所选集合与目标集合相等。程序按ID抽取原文，模型原始手写引文准确率另报，为42.9%；不能用程序抽取的正确原文冒充模型逐字引用正确。高召回、较低精确率表明部分答案圈定范围过宽。

## 当前不能夸大的结论

- **完整理解已有部分明确成绩。** 马冬梅、大话西游告白、迈出第一步的有效要素全部完整命中；唐探立刻有只有部分表达，完整命中为0。不能由几个成功例子推断全部模板都已理解。
- **前缀题还不能完整评价合理推断。** 六份评审均漏回`inference_validity`。主旨吻合分仍可核验，但信息不足时的合理多解没有有效统计，不能据此宣称前缀理解能力为零。后续应先修复评审协议，再作为独立版本测评，不替模型补写字段。
- **BGM能力尚未通过本轮验收。** 五项候选因低信号、残余对白或无音乐而不适用；两项缺原理解；一项模型漏回完整分组，身份契约校验拒绝。只有两项进入有效匹配，且都未命中。声道差分不能可靠分离背景音乐，不能把混合对白或近静音当纯BGM。
- **音乐关联与主旨理解分开。** 新音乐候选模块用Qwen听实际音频、返回关联参考，再检索原GLM理解；没有把人工模板含义塞进音乐答案，也没有证明冻结的原GLM入口已能直接听纯音乐。
- **本轮不是无人工干预的一次通过。** 第一版因调度进程内存过高失败，第二版移除外层重型调度。失败版本、原回执和后续修复分别保留。

## 失败原因与工程边界

- 两个旧原生请求仍未决：狂飙吃鱼整片、不烧心前缀。没有重发或改成已失败；依赖题目继续隔离。
- 薛甄珠吵架的86.1秒音频在本地ASR触碰1024MiB上限，尚未发起模型API。三类任务记中断，BGM因无原理解阻塞。
- 断网复核表明：父进程懒加载可去掉重复依赖，但仍不足以完成该条。模型载入峰值约609MiB，VAD完成后峰值未上升，`transcribe`返回时约756MiB，随后解码被OOM终止。不能把原因全部归给重复导入。
- 保持原权重、`beam_size=5`、逐词时间戳及单路1GB约束，没有通过换小模型、关闭识别或移出计量范围拼成绩。[faster-whisper官方基准](https://github.com/SYSTRAN/faster-whisper#benchmark)中small/int8/beam5的CPU内存约1477MB，可作资源规划参考；本机结论来自上述实测。
- 赵德汉故事题收到`max_tokens`空正文；见面完整题、迈出第一步前缀题缺实际视频证据；不烧心音乐题缺完整分组。均保留响应，没有人工补答案。

## 谁负责理解与评分

GLM-5.3-Flash通过冻结生产模块处理完整参考和真实裁切前缀；固定答题接口用保存的原理解回答长故事题。Qwen承担声画预标注、语义评审，以及新音乐模块的实际音频比较。程序核对输入哈希、引用ID、时间范围、来源、回执和指标。

Qwen辅助标注再由Qwen评审存在同模型偏差。没有人工确认前，这些分数只作为探索结果；此前确认的一处人物动作不视为确认本轮所有主旨标签。
