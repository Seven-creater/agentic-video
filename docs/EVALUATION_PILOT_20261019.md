# 参考驱动智能剪辑系统：40 项探索性评测

原定 **20 个参考 × 2 种方法 = 40 项**已全部结算：30 项进程失败，10 项写出哈希绑定的视频，10 个视频均完成整片声画外评。严格自动合格为 **0/40**。系统已具备可执行、可评测的原型和证据链，尚不能宣称稳定无人值守或已验证完整版优于基础版。

本轮运行中修过环境、提示词、客户端和调度分类，属于**多版本自适应试点**，不能作为干净独立测试的成绩。另行冻结的 20 个确认输入未运行，预算为 0，没有追加批次或 API 调用。

## 输入、输出与流程

输入是实际参考视频及哈希、固定版本三部电影和视觉库、1280×720/30fps/10–180 秒的输出要求，以及有限调用、费用和时间预算。输出是成片或明确失败状态，并附剪辑计划、素材与时间段、调用收据、技术检查、外部评分和逐任务结果。

流程为：参考声画理解 → 检索与必要复看 → 镜头与声音规划 → 按真实音频时长粗剪 → 可选精剪 → 成片审核 → 外部整片评分。素材证据不足允许拒绝，失败仍保留在分母。

热点捕获是上游入口；本轮冻结参考来隔离热榜变化，**不是实时热点服务稳定性试验**。基础版 `baseline_single_pass` 规划粗剪并完成声音和交付审核，不做精剪，仍允许格式纠正；不代表只调用一次 LLM。完整版 `full` 增加精剪和有限反馈修订。两组分别从同一初始素材库规划，并非共享同一粗剪的严格单模块消融。
