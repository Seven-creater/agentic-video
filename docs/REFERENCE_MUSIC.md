# 参考背景音乐与模板检索

本候选分支给项目增加原生纯音频输入，沿用已有Qwen客户端及发送前落盘、收到复用、未决不重发的回执。API使用官方`input_audio`，不发送画面。

`reference_music`比较真实背景音乐的旋律、节奏、音色，忽略对白和说话人。它不从音乐凭空生成道德观点；匹配后返回对应参考的原始理解及其哈希、生产版本。音乐识别成绩与GLM主旨理解成绩分别统计。

`register_reference`保存原始参考理解；生产配置启用`reference_music_index`时在理解完成后登记。`match_reference_music`接收登记表和未见纯音乐片段，返回可能匹配的参考。多个模板共用背景乐时可返回多解，不假定音乐与模板一一对应。查询片段仍有可辨识对白时拒绝把结果当作纯BGM检索成绩。

比较输入是音轨，不保证自动完成了人声分离。`audio_packet`提取的原音轨明确标为混合音频；它可用于音乐初筛，但不能冒充纯BGM题。有效测试片段需要真实无对白窗口或经过独立核验的分离音轨。

音频包只向模型显示不含含义的样本ID和包内边界，不传模板名、文件名、主旨标签、人物信息或标准答案。源哈希、顺序映射、实际回执和模型原始判断保留。共享音乐回执锁串行保护含相同源的操作，未决源不会换目录重复调用。

这是独立候选分支，不修改主分支或线上current。旧版参考理解与新增音乐组件的版本需分别记录，不能把检索出的人工标签冒充原模型理解。

接口依据：[阿里云Qwen-Omni官方文档](https://www.alibabacloud.com/help/en/model-studio/qwen-omni)。
