# 参考视频主旨理解评测记录

**本轮40项都有结果或明确原因，23项取得有效评分，覆盖率57.5%。尚未完成40项全部有效评测。** 标签未经人工确认，以下属于模型辅助成绩，不是人工金标准，也不是整个视频创作系统的端到端出片率。

## 输入、被测对象和输出

先检索24个模板的含义，再核验具体视频，固定10个表达明确主旨的模板及各自参考／未见样本。研究与标注先于正式评分，不按得分挑选成功样本。

被测对象是冻结的原创作项目参考理解阶段，使用GLM-5.3-Flash。直接复用已有真实返回；缺失的原理解不伪造。本轮补评只复用已保存理解，没有重新调用完整／前缀理解，也没有继续剪辑、配音或渲染。

输出为原理解、四类题的答案与逐项判断、源媒体及回执哈希、状态、费用和报告。主旨指视频表达的态度、情感或价值选择；人物、道具、动作作为证据，不代替主旨，也不把所有模板套成“不烧心”的人品判断。

## 怎么打分、谁来打分

1. **主旨要素吻合：**Qwen观看实际视频，逐项核验模型辅助标签是否成立，再对照GLM原输出的句子ID。明确表达计完整，部分、遗漏、矛盾另计。不能替候选把剧情自动升华为它没说过的主旨。程序从原输出提取引文并检查证据时间、身份和回执。单模板分数＝完整命中／核验有效要素，64.3%是模板均值；合并要素16/24＝66.7%，权重不同。
2. **前缀推测：**物理裁掉后续画面与声音，固定开头`min(5秒,时长/3)`，通过原理解入口独立处理。不给整片理解、模板名称或标签。Qwen检查整片主旨吻合，同时判断推测是否由前缀支持、合理、信息不足或矛盾。猜不中最终主旨不自动等于胡编。新契约要求合理性字段，漏回就不能作为完整有效评审。
3. **长故事匹配：**固定答题接口使用保存的原理解，从每模板独立的八段合成长故事中选择段落ID。故事包含“表面像、主旨相反”等干扰。首选命中＝第一个所选ID属于目标集合；范围完全正确＝所选集合等于目标集合；精确率／召回率按段落集合计算。程序据ID提取原文，原始手写引文准确率另报为37.5%，不能用程序补出的原文冒充模型正确引用。
4. **BGM关联：**音乐候选模块让Qwen只听实际音频、比较旋律伴奏，再检索匹配参考的原GLM理解。查询不能带画面、模板名或人工主旨答案。程序按实际返回ID计算关联，不把识别音乐等同于理解任意同曲视频的价值观。共曲允许多解，混合对白或近静音不计纯BGM成绩。

Qwen参与预标注和评审，存在同模型偏差；全部标签仍标为`model_assisted_unconfirmed`。此前仅确认过的一处人物动作，不视为确认本轮十个模板的主旨答案。

## 问题与得到的结论

- **整片理解有能力，但不均衡。** 沟通无奈、失去后珍惜、勇敢行动等模板已有完整表达；“立刻有”的含蓄爱意只有部分表达。不能只拿几个高分案例证明整个系统已经理解所有模板。
- **开头往往不够点题。** 六项中四项推测得到支持或属于合理多解，但完整主旨命中仍低。这两个指标必须分开；不能只用是否猜中最终结局评价开头理解。
- **长故事容易选得过宽。** 高召回而较低精确率、仅1/8范围全对，说明找到相关内容不等于准确定位同主旨情节。
- **音乐尚未通过本轮验收。** 五项因低信号、残余对白或无音乐而不适用，两项缺原理解，一项模型漏回完整分组。声道差分不能替代可靠的人声分离；仅两项有效且均未命中，不足以支持“听BGM就能稳定识别十个模板”的结论。音乐能力位于独立修复分支，不能说冻结原GLM入口已直接支持听纯音乐。
- **资源约束是真实缺口。** 薛甄珠86.1秒音频在本地ASR解码触碰1024MiB，尚未发起原生模型API。断网定位确认VAD已完成，后续解码OOM。去掉父进程重复导入仍不足；没有换模型、减少beam或移出计量范围凑通过。[faster-whisper官方基准](https://github.com/SYSTRAN/faster-whisper#benchmark)的small/int8/beam5 CPU内存约1477MB，仅作为规划参考，本机结论来自实测。
- **两个原生理解请求仍未决。** 狂飙吃鱼整片、不烧心前缀没有重发，也未改成已失败或已收到。当前状态为23项有效、4项未决隔离、3项协议失败、3项缺依赖、5项声音不适用、2项资源阻塞，共40项。
