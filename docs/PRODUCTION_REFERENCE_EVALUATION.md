# 原创作模块理解评测

本分支 `codex/reference-understanding-eval` 在独立 worktree 开发，经 GitHub 提交发布到服务器 `/home/ubuntu/apps/agentic-video-eval`。生产 main 和服务器 current 发布目录保持冻结。本分支不自动合并到生产，不修改生产提示词和服务。

## 被测对象

`production_subject.py` 作为外部观察器启动，先把锁定生产发布的 src 加入导入路径。它使用原 `pipeline.execute`、原 `clean_chain.ROUGH_PROMPTS`、原 OpenCode/GLM 提供方及其验证、台账和有限结构修复规则。在 `model_factory` 注入的观察器拿到 `reference` 阶段真实、已验证返回后，以专用组件结束信号返回；不会进入检索、方案、TTS 或渲染，也不把组件完成算作视频交付。

同 SHA 的原完整理解已有可信回执时优先复用；原可靠性简化输出不混入。历史后续人工修改单独标记。原请求、响应、parsed、理解输出及生产源码哈希均保留，汇总时再次核验。

冻结的旧发布没有新费用钩子，适配器在每次原始请求登记前，通过独立预算进程进行幂等预留，保留原状态机的未决保护。ASR使用同一Whisper版本、权重和参数，在短子进程完成后释放内存，再运行原GLM客户端，所有进程仍计入同一条任务的1024MiB硬限；原生产源码及理解提示词保持不变。上线试点中曾发生的OOM和迟登记费用单独保留，不改写旧调用状态。

## 题型来自2026-10-22会议

1. 01:25 人工标注关键要素，评原理解的吻合程度。报告完整命中率和部分、遗漏、矛盾计数，不加自创总权重。
2. 02:20 实际遮挡未见视频后续，预测隐藏事件，报告事件F1和顺序正确率。
3. 03:10–03:34 从长篇故事定位对应情节，报告首选命中及引用范围。故事明确标为合成；题目不传入答案段落ID。
4. 04:09/05:11 用BGM判断剧情阶段。锁定生产路径的静音代理及ASR没有BGM输入能力，因此当前记录 capability_missing；不让Qwen代答，不用字幕假装听到音乐。

10模板各一条生产参考和一条未见出题视频。模板按目录哈希排序，选择至少两条、最短两条总时长不超过180秒的前10组；组内按时长、SHA排序。该规则在看到答案之前执行，不按得分换样本；这是开发集，不宣称无偏全库估计。

题目准备先于生产答案，Qwen实际看音画提出标签、截断点和故事章节。标签均为 model_assisted_unconfirmed。六份人工卡片由用户明确确认；未确认部分独立报告为暂定结果，不冒称人工金标准。一次原理解供后三类题使用，新增GLM请求是答题，不会更新原理解。

## 命令与产物

```text
reference-eval prepare --inventory ... --runtime ... --receipts ... --output ...
reference-eval run --manifest ... --output ... --workers 2
reference-eval report --manifest ... --output ... --human-reviews ...
```

runtime只包含生产版本/文件哈希、非秘密配置、原库/ASR位置、历史未决排除与已有原输出路径；密钥从服务器现有配置读取，不进入Git。

manifest.json冻结题目和输入；human-review-cards.md、story.json供核对；cases下保存每题答案、分数、证据及失败原因；report.json/md报告40个计划项的覆盖、暂定分数及人工确认范围。blocked/failed/capability_missing保留分母，不与质量零分混淆。没有四类加权总分。

## 运行保护

生产源码、参考媒体和原产物只读；评测代码、依赖、启动入口与结果独立。凭证使用0600文件。统一预算及历史未决预占继续属于原累计100元授权；调整本轮调用额度须留审计记录，不能换目录绕过保护。付费回执留在原财务台账能够核验的位置。

服务由systemd提供内存委托，每路1024MiB、总2800MiB、默认两路，复用资源准入及FFmpeg限流。重启复用收到的回执；未决不重发；单模板错误不终止其余模板。进程被中断留下明确状态，不自动开展新一轮模型工作。

部署按GitHub明确提交SHA安装评测release及独立venv；生产目录不执行git pull。冻结证明在执行前后比较，不把源码main提交号冒充线上发布版本。此前 template_* 独立理解实验仅作归档，其分数不计入本报告。
